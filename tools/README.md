# tools

Ferramentas locais e scripts de produção. Cada uma é um projeto independente nesta pasta.

| Pasta | O que faz |
| --- | --- |
| `cli/` | Comando `boltjz`: ajuda, atualização e o repasse para as outras ferramentas |
| `transcribe/` | Transcreve o roteiro falado de um Reel ou de um vídeo do YouTube |
| `narration/` | Acelera uma narração e sobe o volume, no padrão 1.25x do Bolt |
| `cleanup/` | Corta silêncios e frases repetidas de uma narração |
