# desktop

App de mesa da narração. Grava pelo microfone escolhido, guarda cada projeto numa pasta, acelera, corta e exporta mp3.

```bash
pnpm --filter @boltjz/desktop start
```

A pasta inicial é `~/Documents/video-bolt`. O botão Pasta troca esse lugar.

Acelerar usa velocidade e volume, começando em 1.25 e 2. Cortar abre a onda de volume: o trecho claro fica, o trecho escuro sai. Arraste para selecionar, ouça a seleção, corte ou devolva, e use o zoom. Terminar renderiza de novo sem detectar outra vez.
